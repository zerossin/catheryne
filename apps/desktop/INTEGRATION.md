# 런처 통합 개발 사본

2026-09-26. 실행 중인 사설 런처를 교체하지 않고 UI 통합을 검증하는 개발 사본이다. 제품의 새 정규 원본으로 지정한 것이 아니다. 운영 원본은 `<기존 런처 설치 위치>`이며, 정식 적용 전 양쪽 변경을 비교해야 한다. story-control 코드를 복사하지 않는다.

## 구현

- 기존 홈 및 실행·언락커·채널 설정 유지.
- 사이드바 폭 72 → 160, 홈·스토리·업적·캐릭터·설정 텍스트 메뉴.
- 세 기능 화면은 공통 CompanionPanel을 통해 전환한다.
- 캐릭터 화면: GOOD 원본 가져오기, 항목 개수 표시, 미수집과 0 구분.
- 업적 화면: Akasha ID→카테고리 JSON 가져오기, 검증 대기 표시.
- ProfileStore: LocalAppData/GenshinCompanion/profiles/default 아래 내용 해시 기반 원본 보존, 중복 수입 시 원본 중복 생성 안 함, current.json 원자적 교체.
- 프로필은 현재 default 하나다. 복수 계정 선택 및 계정 식별은 아직 구현하지 않았다. 다른 계정 자료를 같은 프로필로 섞지 않는다.

## 아직 연결하지 않은 것

스토리 실행/조작권 관리, 스캐너 실행/증분 수집, 업적 ID 카탈로그 검증, Paimon 내보내기, 캐릭터 세부 UI·엑셀 추천, 프로필 선택, 설치·업데이트 관리. 메뉴 화면은 이 기능들이 완료되었다고 표시하지 않는다.

## 검증과 실행 주의

공개 아이콘으로 빌드 성공. 창을 띄우지 않는 --self-test 통과: 기존 설정·채널·업데이트 테스트, 새 메뉴 전환, GOOD 미수집 구분, 중복 원본, 실패 시 current 보존, 업적 검증 대기 유지.

실제 화면의 시각 검수 및 클릭 검증은 미실시. 실행 중인 게임 포커스를 보존하기 위해 개발 앱을 표시하지 않았다. 일반 실행은 기존 런처와 동일한 단일 인스턴스 이벤트를 사용하므로 운영 중 실행하지 않는다. 실행 파일 교체, 바로가기 변경, 작업 재시작 및 원격 게시 없음.

후속 통합에서는 현재 운영 소스와 변경점을 비교하고 정규 개발 저장소를 확정한 뒤 옮긴다. 개발 사본과 운영 사본을 동시에 유지보수하지 않는다. 개인정보·실제 수집 자료는 공개 패키지에 포함하지 않는다.

## 스토리 화면 후속 통합

별도 도구에서 진행하라는 문구를 제거하고 StoryClient/StoryPanel을 통해 같은 정규 StoryService를 직접 호출한다. 런처에서 시작·연결·기록 조회·중지·인계·전투 정책 저장·종료를 수행한다. 실제 무입력 서비스 및 설치 화면에서 시작·기존 기록 표시·사용자 인계·종료를 확인했다. 이전 문단의 스토리 미연결 상태는 이 변경으로 대체된다. 자율 목표 계획이나 AI 세션 자동 시작을 구현했다는 뜻은 아니다.
