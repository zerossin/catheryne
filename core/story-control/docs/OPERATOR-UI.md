# 실행 화면

AI에게 목표를 맡기고 진행 상태를 확인하거나 조작권을 가져오는 로컬 화면이다.
기존 관제의 상태·설정·원장과 같은 API를 사용한다. 별도 진행 데이터베이스,
웹 프레임워크, 외부 CDN, 추가 AI 호출은 없다.

## 열기

호스트가 실행 중인 상태에서 같은 상태 폴더를 지정한다.

```sh
story-control ui --state-dir .runtime/my-task
```

기본 브라우저에 열린다. 인증정보는 로컬 연결 파일에서 읽어 URL fragment로 전달한 뒤
주소에서 제거한다. 링크를 공유하지 않는다. 새로고침 후 연결 주소가 없다는 안내가 나오면
위 명령으로 다시 연다. 정적 화면만 인증 없이 제공하고, 상태 조회와 모든 명령은 인증한다.
호스트 기본값은 계속 입력 금지다. 화면을 열거나 닫는 동작 자체는 게임 입력을 발생시키지 않는다.

## 표시와 제어

- 현재 임무·단계, 확인된 모드와 관측 경과 시간, 누적 실행 시간, 단계 시간, AI 응답 대기.
- 완료한 등록 단계와 전체 목록. 단계 개수를 시간 진행률로 바꾸지 않는다.
- 입력 중지: 관리 입력을 취소하고 사용자 조작권을 유지한다. AI가 observe를 호출해도
  사용자 조작권은 바뀌지 않는다. 게임 일시정지를 보장하지 않는다.
- 내가 직접 조작: 같은 취소·조작권 경계를 사용한다. 기존 입력이 반환되기 전에는
  '입력 해제 대기'를 표시한다. 외부 Computer Use 호출을 강제 취소할 수는 없다.
- AI에 다시 맡기기: 입력 반환 후에만 가능하다. 새 관측을 요구하며 미확인 행동 결과를
  지우지 않는다. 이 버튼이 종료된 AI 세션을 깨우거나 새 모델 실행을 만드는 것은 아니다.
- 전투 정책: 자동, 직접 수행, 기록된 실패가 설정 횟수에 도달하면 사용자에게 인계.
  전투 진입은 AI가 등록한 관측으로 판단한다. 자동 전투 기능을 새로 제공하는 설정은 아니다.
- 설정은 관제 원장에 저장하고 재시작 때 복원한다. 사용자 조작권도 보존한다.

전투 직접 수행 중에 AI로 돌려줘도 전투가 계속 관측되면 정책에 따라 다시 인계한다.
전투 도중 자동 수행으로 바꾸려면 정책을 자동으로 저장한 후 AI에 맡긴다.

## 알림

사용자가 '브라우저 알림 허용'을 눌러 권한을 부여하면 완료·도움 필요 시 시스템 알림을
요청한다. 알림 설정은 모든 연결 화면에서 공유된다. 브라우저 권한은 브라우저별이다.
화면 최초 연결 때 과거 이력을 알림으로 재생하지 않으며 같은 이벤트를 반복 통지하지 않는다.
여러 탭을 열면 각 탭이 알릴 수 있다. 화면 닫힘·브라우저 종료·절전·OS 방해 금지에서는
전달을 보장하지 않는다. 닫힌 상태의 상주 알림과 원격 알림은 아직 지원하지 않는다.

## 캣서린 런처 통합

캣서린의 스토리 화면에서 관제 시작·종료, 현재 단계·시간·완료 근거 확인, 입력 중지·사용자 인계·AI 재인계, 전투 정책 저장을 제공한다. UI와 MCP는 같은 사용자 연결 설정 및 관제 API를 사용한다. 별도 브라우저 화면은 선택적 클라이언트이며 필수 실행 경로가 아니다.

시작 시 게임 입력 허용은 기본 꺼짐이며 다음 관제 시작에 적용한다. AI 재인계는 새 관측을 요구하며 AI 세션 자체를 시작하지 않는다. 런처를 닫는 동작은 관제 종료가 아니다. 관제 종료 버튼은 입력을 중지하고 기록을 보존한다.

## AI 운영 계약

자동 진행 중에는 사전에 정한 정책으로 계속 진행한다. 사용자가 control=user로 전환하면
입력을 보내지 않는다. AI는 사용자의 명시적 재개 요청 없이 set_control(agent)를 호출해
중지를 해제하지 않는다. 재개 후 새 화면을 보고 미확인 결과와 단계를 정리한다.
UI는 AI 스케줄러나 자동 장면 판독기가 아니다. 중단된 AI 세션의 재실행은 연결 환경의 책임이다.
