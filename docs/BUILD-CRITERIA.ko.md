# 육성 평가 기준

## 공통 모델

모든 캐릭터는 동일한 `BuildCriterion`과 `CharacterBuild.Evaluate`를 사용한다. 보관함·육성 비교·AI 조회가 같은 100점 결과와 항목별 점수를 사용한다. 사용자 기준이 우선하고, 기존 KQM 기반 14개 역할 기준을 유지한다. 그 외 캐릭터는 자동 자료와 아래 공통 도출 규칙으로 기준을 채운다. 별도의 부분 점수·52점 만점·부분 점수 환산 경로는 없다.

## 원본과 갱신

- MIT 오픈소스 [miao-plugin](https://github.com/yoimiya-kokomi/miao-plugin)의 기본 옵션 가중치, 대표 계산과 특성 참조, 무기 부옵션, 세트 효과를 사용한다. 게임 ID와 GOOD 키의 대응은 Genshin Optimizer 원본을 사용한다. 개인 계정은 외부로 전달하지 않는다.
- 검증 원본을 설치본에 포함해 처음 실행하거나 오프라인이어도 평가한다. 24시간마다 원본 커밋을 확인하고, 변경이 있을 때 자료를 갱신한다. 실패 시 마지막 검증 자료를 유지하고 1시간 뒤 재시도한다.
- 원격 JS는 실행하지 않는다. 숫자 가중치와 특성 참조를 정적으로 읽는다. 라이선스, 문법, 수치 범위, 전체 수집 범위를 검증한다. 장비와 특성 자료도 동일한 카탈로그 캐시에 저장한다.
- 개인 데이터 폴더의 `cache/build-criteria.json`은 재생성 가능한 캐시다. 이전 부분 평가 캐시는 새 모델로 재생성한다. 여행자의 원소별 차이는 범용 기준으로 합치지 않는다.

## 100점 산출식

- 성유물 50: 가중 유효 롤 20 + 주옵션 적합성 15 + 활성 세트 효과 적합성 10 + 강화 5.
- 레벨·돌파 15, 유효 특성 20, 무기 15(레벨·돌파 12 + 적합성 3). 유효 특성이 없는 역할은 특성 20점을 레벨·돌파에 합산한다.
- 부옵션: GOOD의 최대치 환산 롤에 원본 유효 옵션 가중치(0~1)를 곱한다. 목표는 25롤이며 초과 점수는 제한한다.
- 특성: 대표 계산이 일반 공격 특성을 사용하는 경우에만 일반 공격을 포함한다. 스킬·폭발은 원본 계산에서 레벨을 참조하는 특성을 포함한다. 자동 기준의 목표는 기본 레벨 9이며 별자리 보너스는 제외한다. 참조를 찾지 못하면 반응 전용 기준을 제외하고 스킬·폭발을 기본 목표로 사용한다.
- 주옵션: 시계·성배·왕관의 가능한 주옵션과 유효 가중치를 비교하고 부위별 최대 선호도에서 정규화한다. 유효 옵션의 선호 차이가 없는 부위는 가능한 주옵션을 동등하게 평가한다.
- 무기: 무기 종류와 유효 부옵션 가중치를 비교한다. 재련이나 전용 무기 구매를 요구하지 않는다. 부옵션 없는 무기는 공격력 유효 가중치의 35%를 적합성 근사값으로 사용한다.
- 세트: 활성화된 2세트/4세트 효과의 유효 속성과 원소·회복·공격 특성을 비교한다. 4세트는 두 효과를 합쳐 평가하고, 2+2는 두 효과를 각각 평가한다. 대표 역할에서 사용하지 않는 일반 공격·강공격·낙하 공격 보너스는 피해 적합성에서 제외한다.

## 해석과 검증

자동 도출 기준은 속성 적합성의 추정이다. 특정 파티의 최적 세팅, 원충 충족, 조건부 효과의 실제 발동, 전투 피해량을 검증한 점수로 해석하지 않는다. 상세의 산출식과 출처에서 근거를 확인할 수 있다. 계정 관측이 미수집이면 해당 항목과 종합점수를 확정하지 않는다.

가짜 계정으로 수록된 모든 프로필의 100점 배점, 유효 특성 제외, 주옵션 목표, 무기 종류·부옵션, 4세트/2+2 활성 효과, GOOD/게임 ID 일치, 미수집 구분, 자동 갱신·실패 보존, 사용자 기준 우선 적용을 검사한다.

## 누락과 표시

캐릭터 이름에서 평가 원본 ID를 찾을 때 GOOD 연결표와 동일한 게임 카탈로그의 공식 ID를 사용한다. 게임 카탈로그 생성기는 원본 ID를 보존하므로 이름별 임시 예외를 추가하지 않는다.

미수집과 기준 미확인은 0점으로 취급하지 않는다. 공통 100점 배점은 유지하고, 확인된 구성요소의 점수 합을 `≥ 점수 / 100`으로 표시한다. 레벨과 돌파, 각각의 유효 특성, 무기 레벨·돌파·적합성을 독립적으로 계산하므로 한 값이 누락돼도 나머지 기여는 남는다. 확정 종합점수는 모든 항목이 평가됐을 때만 제공한다. 기준이 없는 캐릭터도 레벨·돌파와 장비 강화처럼 역할에 관계없이 확인할 수 있는 항목을 표시한다.

기본 목록은 캐릭터·무기를 등급 내림차순, 레벨 내림차순, 이름순으로 정렬한다. 성유물은 등급 내림차순, 세트 이름, 꽃·깃털·시계·성배·왕관, 강화 내림차순으로 묶는다. 카드 등급과 정렬 등급은 같은 해석을 사용한다.

## 새 캐릭터 ID 연결 갱신

평가 원본과 이름 원본의 리비전을 독립적으로 확인한다. genshin-db의 ID·영문 이름 자료는 별도 갱신되며, 게임 ID가 없는 GOOD 자료는 정확히 일치하는 정규화 이름으로 연결한다. 게임 카탈로그 재빌드나 GOOD ID표 갱신을 기다리지 않는다. 같은 이름으로 두 ID가 매칭되면 추측하지 않는다. 갱신 실패 때는 마지막으로 검증한 자료를 유지한다. 이름 자료만 바뀌면 기존 평가 자료를 다시 내려받지 않는다. 개인 계정은 갱신 요청에 포함하지 않는다.
