# 계정 최신화 판정과 변경 기록

- 메뉴의 느낌표와 최근 최신화는 `CollectionHistory`의 같은 확인 기록을 사용한다. 캐릭터·무기는 7일, 성유물·재료·업적은 24시간이 지나거나 확인 기록이 없으면 최신 확인이 필요하다. 툴팁에 필요한 항목과 확인 주기를 표시한다.
- 최근 확인과 전체 보유량 확인은 다른 의미다. HoYoLAB의 장착 장비, 업적 집계, 계산기 자료, 선택 범위 수집을 각각 표시한다. 최근 자동 조회를 전체 가방 스캔으로 승격하지 않는다.
- 계정 가져오기, 스캔 결과 저장, HoYoLAB 갱신은 같은 관측·변경 기록을 남긴다. 부분 갱신은 다른 항목의 확인 날짜를 바꾸지 않는다. 자료의 관측 시각이 있으면 가져온 시각으로 대체하지 않는다.
- 변경 기록은 실제 이전 관측과 새 관측을 비교한다. 캐릭터 레벨·돌파·별자리·특성, 장비 레벨·재련·주옵션·부옵션·장착 상태, 재료 수량, 업적 집계·개별 확인 증가를 기록한다. 새로 관측한 항목을 실제 신규 획득으로 단정하지 않으며 대응이 불분명한 장비는 이를 표시한다. 누락 필드나 이미지·출처 변경은 육성 변경으로 세지 않는다.
- 개인 저장소에 최근 50회 기록을 보관하고 최신화 화면에서 최근 10회를 보여준다. 최신 기록은 펼치고 과거 기록은 접는다. 변경이 없어도 확인 범위를 보존한다. 기존 전체 스캔의 단계별 완료·재개 기록은 그대로 사용한다.
