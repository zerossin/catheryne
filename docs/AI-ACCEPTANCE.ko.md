# AI 수용 기준과 회귀 시나리오

최신 기존 기능 연결 현황은 [기능 대조표](AI-FUNCTION-PARITY.ko.md)를 따른다. 아래 표의 최초 연결 시점 미구현 항목 중 스캐너/가져오기/내보내기/자동 출석 설정/프리셋/관제 관리/모드 실행기 연결은 후속 구현되었다. 게임 내부 자율 수행과 개별 모드 적용은 별개다.

2026-09-27. 제품 목표는 사용자의 목표를 검증 가능한 결과까지 완주하는 것이다. 도구 호출 성공, 실행 요청, 목표 등록, 게임 결과 확인은 서로 다른 사실이다. 아래 표는 **현재 내장 채팅** 기준이며 외부 AI의 별도 컴퓨터 유즈 능력을 합산하지 않는다.

## 실행/대화 계약

- 일반 질문은 답변, 명시적 행동은 동일한 도메인 도구와 영속 작업 기록을 사용한다.
- UI는 모델의 자연어를 파싱해 버튼/진도를 만들지 않는다. 작업의 Action/State/Result 및 실제 app-server 이벤트를 사용한다.
- HoYoLAB 로그인은 기존 DailyPanel 로그인 명령을 호출한다. 인증 정보는 도구 결과나 대화로 전달하지 않는다.
- 입력창 활동 시간은 해당 AI 응답 시간이고 작업 카드 시간은 도메인 작업 시간이다. `응답 완료`는 `게임 목표 완료`가 아니다.
- 중단 후 재개에는 이전 결과와 중단 원인을 읽고 새로운 관측으로 전제조건을 재확인한다.
- 게임이 꺼져 있어도 읽기/설정/목표 등록은 가능하다. 게임 관측·입력은 실제 창, 최신 프레임, 활성 입력 소유권이 필요하다.

## 지식 원본

게임 지식을 '절대정보'로 보지 않는다. 버전·언어·정규 ID·출처·갱신 시각을 가진 읽기 전용 카탈로그로 관리하고, 사용자 계정 관측과 분리한다. 기존 업적 카탈로그 및 GOOD를 우선 활용한다. 임무/육성 지식은 향후 같은 조회 계약 아래 수집 어댑터로 연결한다. 중앙 서버 없이 로컬 캐시부터 가능하다. 계정 DB에 추론을 확인 사실로 저장하지 않는다.

## 검증

`--self-test`는 임시 합성 계정만 사용한다. 기존 도구 계약 테스트에 FPS 저장, 무효 값 거절과 이전 값 보존, 실행 중 변경 차단, 언락커 설정, 로그인 Action, 컨텍스트 최신 턴과 누적 토큰 구분을 포함한다. MCP 테스트는 동일 구현의 도구 목록과 로컬 조회를 확인한다.

유료 연동 시험은 `CATHERYNE_TEST_MODEL`과 `CATHERYNE_TEST_EFFORT`를 명시하지 않으면 종료 코드 64로 중단한다. 실제 모델 목록과 지원 추론 수준을 검증하며 고가 기본 모델로 자동 대체하지 않는다. 일반 로컬 테스트에서는 모델 호출·게임 입력·출석 수령을 하지 않는다.

이 문서의 예시는 비개인적 제품 시나리오다. 실제 UID·재고·대화·성공/실패 로그와 개인 테스트는 사용자 데이터 폴더에 두고 공개 저장소에 넣지 않는다.

Windows 자동 HDR: query.launcher.windows_auto_hdr의 Supported/Enabled/Error로 전역 선호 설정을 읽는다. Enabled=null은 미설정 Windows 기본값이며 false로 추측하지 않는다. display.windows_auto_hdr의 enabled:boolean과 프리셋은 공통 WindowsAutoHdr 경로로 저장·재조회한다. 게임별 예외는 보존하고 저장 성공을 실제 게임 HDR 적용 확인으로 보고하지 않는다.
