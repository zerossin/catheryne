# 공개 자료 자동 갱신 점검

2026-10-01 기준. 이 문서는 자료의 책임과 갱신 경계를 기록한다. 계정 기록·자격 증명·게임 화면은 포함하지 않는다.

## 결론과 적용 범위

기존에는 이름·이미지·HoYoLAB ID 매핑·성유물 계산표가 설치본에 고정돼 있었다. 재료와 추천 기준은 별도로 갱신되어 서로 다른 자료 시점이 섞일 수 있었다. 이제 앱에 포함된 `game_catalog.py`가 공개 자료를 한 묶음으로 만들어 원자적으로 교체한다. GUI와 AI, HoYoLAB 변환, 재료 이름 및 성유물 계산은 `GameDataCatalog`의 같은 검증 스냅샷을 읽는다.

새 캐릭터·무기·성유물·재료와 일반적인 버전/시즌 갱신은 출처에 공개된 뒤 앱 재설치 없이 반영할 수 있다. 출처에 아직 없는 정보, 공략의 최신성, 새로운 전투 기믹의 정답, 외부 API/게임 UI 구조 변경까지 자동으로 보장하는 구조는 아니다. 모르는 값을 기존 캐릭터·0개·완료 상태로 추측하지 않는다.

## 실패와 저장 정책

- 새 묶음의 필수 자료가 누락되거나 번역·ID·리비전이 충돌하면 활성화하지 않는다. 마지막 검증 자료를 사용하고 다음 확인에서 재시도한다.
- 개별 원본 blob 캐시는 해시를 다시 확인한다. 손상된 blob은 재다운로드한다. 전체 캐시도 앱에서 검증하며 오류가 있으면 실행 중 정상 스냅샷을 유지한다.
- 공개 캐시에는 계정·쿠키·보유 목록을 보내지 않는다. 캐시는 사용자 데이터 폴더에 있고 소스 저장소에 저장하지 않는다.
- 신규 ID가 GOOD에 아직 없으면 공식 게임 ID와 원본 정보를 보존한다. 임의의 기존 키에 끼워 맞추지 않는다.
- 진행 중 환상극의 계정·자료 참조와 과거 기록은 새 자료로 소급 변경하지 않는다. 새 시즌 여부를 별도로 표시한다.
- `catheryne_query`의 `data_sources`는 공개 자료 리비전·갱신 상태·검증된 개수를 읽는 기계용 조회다. UI에 상시 출처 문구나 설정을 추가하지 않는다.

## 검증

- 공개 자료 실갱신: 캐릭터 ID 124개, 재료 921개. 모든 소비자가 같은 묶음을 읽는지 확인.
- Python 회귀 검사: 신규 ID, 혼합 리비전, 번역/ID 충돌, GOOD 키 변경, blob 손상 복구, 실패 시 기존 파일 보존, 해석 불가능한 특성 보정의 미확인 처리.
- 앱 회귀 검사: 자료 묶음 검증·손상 캐시 유지, 정확한 서버 시즌 경계, 공식 기록 캐시 만료, 업적 충돌, 버전 이름/날짜 검증, 미확인 신캐 자리 순서.
- 설치본은 검증한 실행 파일·갱신 모듈·공개 자료만 백업 후 반영한다. 게임 제어/실제 스캔을 실행하지 않는다.
