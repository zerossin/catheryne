# 캐릭터 상세와 육성 점수

캐릭터 목록은 초상화, 원소 색, 별자리, 레벨 띠, 이름을 사용한다. 선택 상세는 목록 아래 전체 폭을 쓰고, 목록 페이지 동작은 목록 바로 아래에 둔다. 캐릭터 상세의 장비에는 착용자를 반복하지 않는다. 무기/성유물 단독 탐색의 착용자 정보는 유지한다. 장비 등급·부위·잠금·기존 CV/RV는 장비 상세에 보존한다. HoYoLAB 표시 특성도 미정규화 상태에서는 별도 접힌 상세에 보존한다.

## 단일 모델

`BuildCriterion`이 역할별 목표와 유효 옵션을 소유한다. `CharacterBuild.Evaluate`의 결과를 캐릭터 상세, 육성 비교, `build_analysis.development_score`가 함께 사용한다. 기존 선택 옵션 설정은 새 기준이 저장되기 전까지 같은 의미로 읽고, 육성 비교에서 변경하면 기준에 저장한다. 계정 GOOD/원본 장비는 수정하지 않는다. 사용자 기준은 개인 설정의 `buildCriterion.<identity>`에 저장한다.

기본 역할 14개: 파루잔(6돌 전후), 방랑자, 푸리나, 나히다, 종려, 라이덴 쇼군, 한운, 신학, 시틀라리, 산고노미야 코코미, 호두, 느비예트, 카에데하라 카즈하, 닐루. 출처는 각 기준에 KQM 가이드 URL과 확인 날짜를 보존한다. 역할이 다르거나 기본 기준이 없는 캐릭터는 평가 기준에서 설정한다. 원소나 무기 종류만으로 역할을 추측하지 않는다. 팀별 원충 임계값·원소 피해·반응 소유권을 이 점수로 판정하지 않는다.

## 산출식 v1 (2026-09-30)

100점은 아래 목표를 달성한 상태다. 순위 백분위, DPS 비율, 게임 공식 점수가 아니다. 캐릭터 간 성능 순위를 나타내지 않는다.

| 항목 | 배점 | 목표 대비 달성률 |
|---|---:|---|
| 캐릭터 레벨·돌파 | 15 | 레벨 / 기준 레벨 × 0.8 + 돌파 / 6 × 0.2 |
| 유효 특성 | 20 | 유효 특성만 목표 레벨 대비 달성률을 평균 |
| 무기 | 15 | 레벨 / 90 × 0.6 + 돌파 / 6 × 0.2 + 역할에 적합한 무기 여부 × 0.2 |
| 성유물 유효 옵션 | 20 | 유효 옵션 RV 하한 합 / 100 / 목표 유효 롤 수 |
| 성유물 주옵션 | 15 | 시계·성배·왕관의 허용 주옵션 일치 수 / 3 |
| 성유물 세트 | 10 | 추천 4세트의 부위 수 또는 2+2 조합의 부위 수 / 4 중 최댓값 |
| 성유물 강화 | 5 | 각 부위 강화 레벨 / 20의 합 / 5 |

각 달성률을 0–1로 제한하고 배점을 곱한 뒤 합산한다. 특성 육성이 역할의 목표에 포함되지 않으면 특성은 해당 없음(0점 배점)으로 표시하고 20점을 레벨·돌파로 합산한다. 목표 특성 레벨 6/8/9, 기본 목표 유효 롤 25, 배점과 등급 경계(85/65)는 캣서린의 비교용 정책이며 KQM의 공식 종합 점수가 아니다. 기준에서 목표를 수정할 수 있다. 별자리·재련 구매나 전용 무기를 요구하지 않으며 적합한 저등급 무기도 같은 적합성 점수를 받는다.

RV는 기존 Genshin Optimizer 반올림 보정 표를 재사용한다. 최대치 부옵션 1회가 유효 롤 1회에 해당한다. 표시 반올림 때문에 범위가 생기면 하한을 쓴다. 평범한 강화 횟수와 구분한다. 캐릭터 역할에 필요한 옵션만 합산하며 종려/신학/한운은 페보니우스 무기를 장착할 때 치명타 확률을 추가로 유효 판정한다. 파루잔의 C6 조건은 별자리 보너스 가점이 아니라 유효 특성/세트 선택 조건이다.

미수집 레벨·돌파·유효 특성·부옵션 등은 nullable 점수로 남기고 종합 점수를 확정하지 않는다. 수집된 장비 목록에서 확인된 미장착은 0점으로 평가한다. 미수집을 0으로 치환하거나 확인된 항목만 100점으로 재정규화하지 않는다. 중복 부위·비정상 RV는 성유물 평가를 보류한다. HoYoLAB 특성은 정규화된 GOOD 기본 레벨만 평가하고 별자리 효과가 포함된 표시 레벨을 추측해 대입하지 않는다.

## 조사

- KQM 성유물 가이드: https://keqingmains.com/misc/artifacts/ — RV 개념과 캐릭터별 옵션 평가의 필요성.
- Genshin Optimizer: https://github.com/frzyc/genshin-optimizer — 기존 RV 표와 반올림 보정의 원본. 전체 피해 최적화 엔진을 복제하지 않는다.
- RPG Build Optimizer: https://github.com/natcat38/rpg-build-optimizer/blob/85d6091fb449844118f0b8dcb352ffd78dedd705/src/roster/buildScore.ts — 0–100 종합 점수 사례를 조사했다. 모든 특성과 CV를 일괄 적용하고 미수집을 0점 처리하는 부분은 이 프로젝트의 역할/미수집 원칙과 다르므로 코드나 추천 데이터는 복사하지 않았다.

KQM 권장 옵션/특성 우선순위를 요약한 기준만 사용하며 가이드 본문을 배포하지 않는다. 출처 URL과 확인 날짜는 선택 상세에서 확인한다. 점수 계산은 네트워크 요청 없이 로컬 장비로 수행한다.
