# 캣서린 사용 안내

[English](USER-GUIDE.md) · **한국어**

## 설치와 시작

Windows 10/11 x64와 설치된 원신이 필요합니다.

1. `Catheryne-Setup`으로 설치하고 캣서린을 여세요.
2. 게임 위치를 확인하고 필요한 구성요소를 준비하세요. FPS 제한 해제는 선택 사항입니다.
3. 앱을 사용하세요. 게임 실행·캡처·로컬 자료 조회·파일 가져오기와 내보내기는 로그인 없이 사용할 수 있습니다.

앱은 한국어로 시작합니다. **설정 → 일반 설정 → 언어**에서 영어를 선택한 뒤 다시 열면 적용됩니다. 필요한 구성요소는 나중에 **설정 → 설치·구성요소 관리**에서 준비할 수 있습니다.

## 계정 연결

상단 계정 메뉴에서 필요한 서비스를 선택하세요.

- **ChatGPT:** 내장 AI 채팅. 별도로 설치한 호환 Codex 데스크톱 환경도 필요합니다. 캣서린에는 포함하지 않으며 [공식 설치 안내](https://learn.chatgpt.com/docs/quickstart)를 따르세요.
- **HoYoLAB:** 계정 최신화, 출석, 레진과 여행자 일기.
- **리딤 계정:** 코드 등록. HoYoLAB과 별도로 연결합니다.

로그인 창에서 직접 로그인하고, 안내가 나오면 사용할 원신 계정을 선택하세요. 자동 출석과 리딤코드 자동 등록은 직접 켜야 하며, PC가 꺼지거나 절전 상태일 때는 실행되지 않습니다.

## 자료 최신화

**내 계정 → 최신화**에서 자료를 갱신하거나 GOOD·계정·업적 파일을 가져오세요. 캐릭터와 장착 장비는 HoYoLAB으로, 미장착 장비와 개별 업적은 게임 스캔으로 수집할 수 있습니다.

스캔 준비 화면의 안내에 맞춰 게임 언어를 영어로 설정하세요. 장비 스캔은 지원하는 화면 비율과 HDR 끄기도 필요합니다. 게임을 화면에 표시하고 스캔 중에는 직접 조작을 피하세요. 같은 화면에서 중단하고 이어서 수집할 수 있습니다.

최신화에 실패해도 기존 자료는 유지합니다. HoYoLAB의 업적 합계만으로 개별 업적 완료 여부를 확인할 수는 없습니다.

## 캐릭터와 장비 확인

**내 계정**에서 캐릭터나 장비를 선택하면 상세를 볼 수 있습니다. 필요한 자료가 있는 무기는 능력치와 재련 효과를, 성유물은 주·부옵션과 평가를 표시합니다. 성유물 목록에서도 주옵션을 확인할 수 있습니다.

성유물 목록의 **정리 판단** 필터에서 정리 후보·강화 확인·보호 항목을 확인하세요. 선택하면 판단 근거와 대체 장비를 볼 수 있고 **AI 상담**으로 더 검토할 수 있습니다. 장착·잠금·저장 빌드에 사용한 장비는 보호합니다. 실제 소비 전에 게임의 현재 상태를 확인하세요. 캣서린이 성유물을 자동으로 처분하지는 않습니다.

캐릭터 상세의 **육성 계획**과 **육성 비교**에서 필요한 재료를 확인하고 역할별 기준으로 육성 상태를 비교하세요.

## AI 사용

ChatGPT를 연결한 뒤 채팅에 질문이나 작업을 입력하고 보내세요. “이 캐릭터는 무엇부터 육성하면 좋을까?”, “현재 게임 화면 보고 판단해줘”처럼 요청할 수 있습니다.

첨부 메뉴에서 파일을 추가하거나 게임 화면을 캡처하세요. 복사한 이미지나 파일을 입력창에 **Ctrl+V**로 붙여넣어도 됩니다. PNG·JPG·JPEG·WebP와 TXT·MD·JSON·CSV를 지원하며, 텍스트 파일은 500KB 이하로 선택하세요. 보내기를 누르기 전에는 첨부를 전송하지 않습니다.

채팅 글을 드래그해 선택하고 복사할 수 있습니다. AI 작업 카드에서 중단하면 직접 조작으로 돌아갑니다. 마지막으로 중단한 요청은 **수정 후 다시 보내기**로 고쳐서 보낼 수 있습니다. 원래 대화는 기록에 남고, 수정본은 그 요청 이전의 대화를 이어받은 새 대화에서 전송합니다.

실행을 요청하면 AI는 목표의 완료를 확인할 때까지 이어갑니다. 반복 실패에는 다른 방법을 확인하고, 진행이 없으면 도움을 요청합니다. 필수 질문은 채팅 카드와 상단의 **응답 필요**에서 확인할 수 있습니다. **중단**한 작업은 자동으로 재개하지 않습니다.

## 도전 콘텐츠 준비

**플레이 → 나선비경** 또는 **지맥 제압전**에서 보유 캐릭터에 맞는 편성을 추천받으세요. 편성의 빌드를 저장하고 AI에게 상담하거나, 결과를 기록해 시도별로 비교할 수 있습니다.

화면을 열면 저장된 추천을 보여 줍니다. **출전 설정 → 추천 갱신**으로 현재 계정과 시즌 자료를 반영해 다시 계산하세요. 추천이 없으면 출전 설정이 펼쳐지고 **파티 추천**이 표시됩니다. **목표 메모**는 저장·AI 상담용이며 층·별 수·시간 필터가 아닙니다. 나선 추천은 12층 전반·후반을 대상으로 합니다. 지맥의 난이도는 1~3에서 재사용을 허용하고 4~6에서 캐릭터·무기·성유물 중복을 제한하며, 난이도별 클리어 가능성을 예측하지 않습니다.

**플레이 → 환상극**의 **채팅에서 시작**으로 새 도전을 시작하거나 이어가세요. 선택·결과 화면을 보내면 다음 선택과 출전 조합을 상담할 수 있습니다. 전투와 게임 안의 선택은 직접 진행합니다.

## 화면 설정

**화면·성능**에서 FPS·화면 모드와 지원되는 Windows HDR·자동 HDR을 설정하세요. **AI 프리셋**은 현재 설정을 보관하고 1920×1080·60 FPS·HDR 끄기로 전환합니다. **내 프리셋**으로 보관한 설정을 복원할 수 있습니다. Windows HDR은 즉시 바뀌며 게임 실행 설정은 다음 실행부터 적용됩니다.

## 모드 관리

**화면·성능 → 모드**에서 ZIP·7z·RAR 또는 폴더를 가져온 뒤 필요한 모드를 켜세요. 가져온 모드와 기본 제공 모드는 처음에는 꺼져 있으며, 필요한 구성요소는 사용 시 준비합니다.

검색·분류로 항목을 찾고 상세에서 설정과 원본 페이지를 확인하세요. 모드를 꺼도 파일은 보관합니다. 모드 변경은 게임을 종료한 상태에서 진행하며, 호환 여부는 모드와 게임 버전에 따라 달라집니다.

변경 가능한 단축키는 상세에서 키를 클릭한 뒤 새 조합을 누르고, ↺로 원래 키를 복원하세요. 켜진 모드와의 키 겹침 가능성을 표시하며 변경은 다음 게임 실행부터 적용합니다.

## 화면 캡처

**화면·성능 → 캡처**를 열거나, 설정한 원신이 전면에 있을 때 **Ctrl+Shift+F12**를 누르세요.

기본 저장 위치는 **사진/Catheryne**입니다. 캡처 화면에서 단축키와 폴더를 변경할 수 있습니다. HDR 화면도 공유하기 쉬운 일반 PNG로 보정해 저장합니다. 최근 캡처를 채팅에 첨부하거나 복사·열기 할 수 있습니다.

채팅 첨부 메뉴의 **캡처하기**로 찍어도 됩니다. 원신 창이 최소화되어 있다면 먼저 복원하세요.

## 알림

캡처, 켜 둔 레진·출석 알림, AI 도움 요청은 Windows 알림으로 표시합니다. 조작 중 확인이 필요한 상황도 알림을 받고 싶다면 스토리 설정에서 알림을 켜세요. 답변이 필요한 질문은 알림 센터에서 다시 열 수 있고, 답변하면 관련 알림을 지웁니다. 긴급 알림은 Windows 권한과 방해 금지 설정을 따릅니다. 알림을 누르면 관련 화면으로 이동하며 게임 조작은 자동 재개하지 않습니다.

**설정 → 일반 설정 → Windows 알림 설정**에서 알림을 관리할 수 있습니다. Windows에서 알림을 끈 경우에는 표시되지 않습니다.

## 업데이트와 제거

**설정 → 일반 설정 → 앱 업데이트**에서 새 버전을 확인하세요. 자동 업데이트는 선택 사항이며 작업이 없는 다음 실행에 설치합니다. 공개 릴리스가 제공되면 업데이트를 받을 수 있습니다.

Windows **설치된 앱**에서 제거하세요. 개인 설정과 기록은 재설치를 위해 보관하며, 원신과 별도로 설치한 외부 도구는 제거하지 않습니다.
