# 성유물 정리 판단 설계

개발 참고 문서입니다. 실제 사용법은 [사용 안내](USER-GUIDE.ko.md#캐릭터와-장비-확인)를 참고하세요.

## 조사와 도입 범위

[KQM 성유물 공략](https://keqingmains.com/misc/artifacts/)은 주옵션, 캐릭터별 유효 부옵션, 다른 캐릭터 및 비세트 활용을 함께 검토하도록 권한다. 강화한 장비는 경험치 재료로, +0 장비는 합성 재료로 검토하는 구분도 제시한다. 제작사의 공인 폐기 판정표로 취급하지 않는다.

[Genshin Optimizer](https://github.com/frzyc/genshin-optimizer)는 장비 조합 최적화와 강화 후 개선 가능성을 다루는 MIT 프로젝트다. 캣서린이 이미 사용하는 검증된 GOOD 자료와 롤 값 표를 재사용한다. 외부 계산 엔진이나 새 실행 파일은 추가하지 않는다. 원문 공략과 커뮤니티 표를 복사하거나 실행하지 않는다.

이번 기능은 저장 자료를 읽어 판단을 돕는다. 게임의 잠금 변경, 판매, 분해, 합성, 강화 재료 투입을 실행하지 않는다.

## 하나의 판단 모델

ArtifactReview가 InventoryPanel과 catheryne_query의 artifact_review를 함께 제공한다. AccountMerge.Inventory, CharacterBuild의 사용자/역할 기준, BuildCriteriaCatalog의 미보유 캐릭터 기본 기준, BuildAnalysis.Score의 같은 RV 표를 사용한다. 자동 갱신으로 추가된 기준도 다음 조회에 반영한다. 세트가 맞지 않는 장비도 비세트로 사용할 수 있으므로 활용 계산에서 배제하지 않는다.

- 장착, 게임 잠금, 선택 계정의 나선·지맥 저장 빌드는 보호한다. 저장 빌드 개체 ID 또는 동일 옵션의 서명을 대조한다. 식별이 모호하면 보존 쪽으로 판단한다.
- 잠금·장착 상태 누락, 대응 미확인 관측, 불가능한 옵션·강화 합계, 낮은 등급의 특수 세트는 판단 보류다. 저장 빌드 읽기에 실패하면 정리 후보를 만들지 않는다.
- 유효 옵션 RV 상한을 롤 단위로 표시하고 남은 강화에서 가능한 최대치를 더한다. 3줄 장비의 새 4번째 옵션도 고려한다. 이는 상한이며 성공 확률이나 피해량이 아니다.
- 보관/강화 확인의 4롤은 앱의 안내 참고선이다. 공인 폐기 기준이나 최적 장비 판정이 아니다. 가중 피해량, 원충 충족, 실제 파티 버프를 시뮬레이션하지 않는다.
- 정리 후보는 강화가 끝난 5성만 대상으로 한다. 같은 세트·부위·주옵션의 대체품 두 개 이상이 모든 부옵션 수치에서 같거나 높고 적어도 하나에서 높아야 한다. 동일 ID/식별 불가 동일 옵션을 두 대체품으로 세지 않는다.
- 강화한 후보는 강화 재료 활용을 우선 제시한다. 여러 파티용 추가 수량, 향후 캐릭터와 특수 운용은 사용자가 확인해야 한다. 후보 판정은 소비 허가가 아니다.

## UI와 검증

기존 성유물 목록과 상세를 유지하고 정리 판단 필터와 카드 표시를 추가한다. 상세에는 근거, 유효 롤, 미강화품의 최대치, 대체품, AI 상담을 제공한다. 계산과 파일 조회는 목록을 여는 작업 스레드에서 실행하며 페이지를 바꿀 때 재계산하지 않는다. AI 상담은 기존 흐름대로 초안만 준비한다.

회귀 검증은 보호/잠금/저장 빌드, 누락 자료, 강화 가능성, 대체품 중복·세트 차이, 실제 저장소와 AI 조회의 일치, 읽기 실패, 입력 불변성, 필터·빈 결과, 좁은/넓은 화면 및 2,000개 장비 조회를 포함한다.
