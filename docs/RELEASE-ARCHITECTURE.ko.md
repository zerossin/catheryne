# GitHub Releases 배포 구조

2026-10-04 기준. 소스 공개와 사용자 설치본 배포를 구분한다. 원격 게시에는 별도 승인이 필요하다.

## 단일 원본과 경계

전체 Git 저장소가 개발 원본이며 `apps/desktop/VERSION`이 앱 버전의 원본이다. 앱 UI, CLI와 AI는 같은 `core`·`modules` 실행 모델을 사용한다. 외부 소스와 라이선스는 `third_party`에 유지한다.

새 설치 위치는 `%LOCALAPPDATA%/Programs/Catheryne`, 개인 자료 위치는 `%LOCALAPPDATA%/Catheryne`이다. 기존 설치 경로를 유지하며 계정·인증·설정·작업 기록·캡처는 소스와 설치 파일에 포함하지 않는다. 무시 규칙만으로 기존 Git 기록이 정리되는 것은 아니므로 `scripts/check-public.py --history`로 공개할 기록도 검사한다.

## 소스 공개

루트 MIT 라이선스는 자체 코드·문서에 적용한다. 모듈과 외부 소스의 라이선스를 유지하고, 그림·게임 자료의 권리는 [라이선스 범위](../NOTICE.md)와 [외부 구성요소](../apps/desktop/THIRD-PARTY.md)에 구분한다. 아이콘과 환영 그림은 소유자 직접 제작으로 확인했다. 사용자가 선택한 원신 공식 콜롬비나 배경과 홍보 제목 제거 편집본의 원본·저작권·해시·편집 기록은 branding/README.md에 기록하며 코드 MIT 라이선스와 구분한다. 이전 배경이 남은 로컬 Git 이력은 공개 스냅샷에 포함하지 않는다.

소스 산출물은 검증한 Git 커밋 또는 태그 전체다. GitHub의 전체 태그 압축 파일이나 `git archive`를 사용한다. `package.ps1`은 설치 파일과 SHA256SUMS를 같은 날짜별 배포 폴더에 생성한다. 불완전한 desktop 소스 ZIP은 제공하지 않는다. 실험용 `labs`는 설치본에 포함하지 않는다.

영어 README를 기본으로 하고 한국어 README로 연결한다. README는 사용자 소개와 설치 조건에 집중하고 개발·배포 세부 사항은 이 문서와 개별 가이드에 둔다.

## 설치본과 업데이트

사용자 산출물은 `Catheryne-Setup-VERSION.exe`다. 앱·업데이트 도우미·유지보수 스캐너·Python/MCP·필요한 라이선스를 포함하며 게임·FPS 언락커·Codex는 포함하지 않는다. C# 입력 목록은 `build-sources.txt`로 관리한다.

앱 업데이트는 구현되어 있다. `AppUpdateService`가 공통 `resources.json.projectUrl`의 공개 GitHub 정식 릴리스를 확인하고 버전·설치 파일 이름·크기·SHA-256 digest를 검증한다. `AppUpdater`는 작업 종료를 확인한 뒤 기존 Inno Setup을 같은 설치 경로에 실행한다. 구성요소 `UpdateService`와 앱 업데이트를 혼용하지 않는다. 자동 업데이트는 기본 꺼짐이다. 규약과 검증은 [앱 업데이트](APP-UPDATES.ko.md)를 따른다.

현재 개발본은 공개 저장소 주소가 지정되지 않아 실제 릴리스를 조회할 수 없다. `package.ps1 -Repository OWNER/REPO`가 패키지의 공통 주소를 설정한다. 별도 앱 업데이트 메타데이터 서버는 사용하지 않는다.

설치 관리자는 이전 명세에서 빠진 앱 소유 파일 중 해시가 일치하는 파일만 정리한다. 업데이트와 제거는 개인 자료, 원신과 외부 프로그램을 삭제하지 않는다.

## 공개 전 확인

- 소스: 현재 파일과 Git 기록의 개인정보 검사, 언어 자료 검사, 자체 검사, 외부 라이선스와 그림 권리 확인.
- 설치본: 깨끗한 체크아웃의 빌드·패키징, 설치·경로 유지 업데이트·제거 검사, 배포 해시 확인.
- 게시: 공개 저장소·태그·배포 대상 결정, 릴리스 초안 검토 후 명시적 승인으로 게시. 코드 서명은 배포자와 서명 자격증명을 정한 뒤 적용하며, 현재 서명 완료를 주장하지 않는다.

`public-data.yml`은 개인정보·언어 자료를 검사한다. `windows-validation.yml`은 Windows에서 앱·네이티브 도우미·스캐너·Python을 빌드하고 한영 자체 검사·코어·AI 계약을 검사한다. 자동 게시 권한은 없으며 실제 GitHub 실행 결과는 저장소 게시 후 확인한다. 로컬 전체 설치 검사는 `test-full-install.ps1`, 업데이트 도우미 검사는 `test-app-updates.ps1`을 사용한다. 실제 공개 릴리스에서의 업데이트 조회와 코드 서명은 아직 검증하지 않았다. 서명 키와 토큰을 저장소에 넣지 않는다.
