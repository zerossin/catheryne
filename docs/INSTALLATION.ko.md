# 캣서린 설치와 수명주기

> 개발·통합 참고 문서입니다. 사용자 안내: [English](USER-GUIDE.md) · [한국어](USER-GUIDE.ko.md)

## 설치와 저장소

단일 Catheryne-Setup 설치 프로그램이 앱 파일, 시작 메뉴 바로가기, Windows 설치된 앱 등록과 제거 프로그램을 관리한다. 새 사용자의 기본 위치는 `%LOCALAPPDATA%\Programs\Catheryne`이며 기존 설치 위치와 사용자 지정 경로를 유지한다. 바탕화면 바로가기는 선택 항목이다. 바로가기는 `--preview`로 홈을 열며 게임을 자동 실행하지 않는다.

개인 설정, 계정 원본, 프리셋, 작업 기록, 로그인 프로필과 관리 구성요소는 `%LOCALAPPDATA%\Catheryne`에 저장한다. 개인 원본은 설치 파일과 소스 패키지에 포함하지 않는다. 앱 실행 시 바로가기를 반복 생성하지 않는다. 별도 설정 바로가기는 해당 앱을 가리킬 때만 설치 관리자가 제거한다.

## 업데이트와 제거

일반 설정의 **앱 업데이트**에서 새 버전을 확인하고 설치할 수 있다. **앱 자동 업데이트**는 선택 사항이며, 켜면 새 버전을 다운로드하고 작업이 없는 다음 실행에 설치한다. 게임 바로 시작은 자동 설치로 지연시키지 않는다. 공식 GitHub 저장소가 지정된 배포본에서 제공하며 자세한 배포 규약은 [앱 업데이트](APP-UPDATES.ko.md)를 참고한다.

새 설치 프로그램을 실행하면 기존 위치를 사용한다. 이전 설치 명세에서 빠진 파일은 기존 해시가 일치할 때만 제거한다. 사용자가 만든 파일이나 수정된 파일은 보존한다. 게임이나 수집 작업이 실행 중이면 교체하지 않는다. 앱과 매일 실행 도우미는 설치 전 종료한다.

Windows 설치된 앱에서 제거한다. 설치 파일, 앱 등록, 소유 바로가기와 앱의 자동 시작 항목을 제거하며 개인 자료는 보존한다. 재설치 후 같은 자료를 사용한다. 원신, HoYoPlay, Codex 및 사용자가 별도로 설치한 외부 프로그램은 제거하지 않는다.

Python 3.13.15와 MCP 의존성은 설치 파일에 포함한다. 사용자는 Python이나 개발 도구를 별도로 설치하지 않는다. 구성요소 관리자가 번들을 검증한 후 사용자 데이터의 관리 환경에 설치하며 이전 환경은 성공한 전환 뒤 정리한다.

## 실행 경계

AppRuntime이 실제 쓰기 경로로 Windows 패키지 리디렉션을 판별한다. 필요하면 Windows 데스크톱 실행 경계로 GUI와 MCP를 전달한다. 동일 사용자 전용 파이프를 사용하며 인증정보와 도구 요청을 중간 파일에 기록하지 않는다. 공개 경로 문자열만 같다고 자료 공유를 가정하지 않는다.

## 검증

2026-09-28: 별도 설치 식별자의 격리 검증에서 설치, 경로 유지 업데이트, 이전 소유 파일 정리, 사용자 파일 보존, 제거와 등록 해제를 확인했다. 실제 설치본 0.2.0에도 앱 등록과 바로가기를 적용했다. 기존 개인 자료는 파일 해시 비교 후 정규 AppData로 이전했고 별도 기록에 검증 근거를 보존했다.

보안 검사는 새 실행 파일과 설치 프로그램의 정확한 해시별로 수행한다. 보안 차단 파일을 복원하거나 제외 설정으로 우회하지 않는다. 일반 설치 검증은 게임 입력이나 FPS 해제의 성공 증거가 아니다. 새 Windows 사용자 계정에서의 첫 로그인과 실제 게임 입력은 별도 검증 범위다.
