2026-10-04. 앱 소스 기준 `20daa38`; 배포 스크립트와 문서는 이번 점검에서 보완했다. 실행 코드 변경은 없다.

## 통과한 검사

- 별도 깨끗한 체크아웃에서 WPF 앱, 업데이트 도우미, 캡처·이미지·Windows 알림 DLL, 두 스캐너를 새로 빌드했다. Python 3.13.15와 고정 직접 의존성도 새로 준비했다.
- 현재 파일과 전체 Git 이력의 개인정보 검사, 번역 검사, 공개 경계 테스트 4개, 번역 테스트 3개, 배포 폴더 정리 검사를 통과했다.
- 코어 Python 테스트 169개 중 159개 통과·10개 조건부 생략, Node 어댑터 테스트 6개 통과. 실제 게임 입력을 보내지 않았다.
- 한국어·영어 앱 자체 검사를 순서대로 통과했다. 최초 실행 화면, 설정 보존, 화면 프리셋, 모의 서비스와 업데이트 검증을 포함한다.
- 실제 번들 Python에서 AI 어댑터 테스트 14개와 MCP 초기화·21개 도구 계약 검사를 통과했다.
- 전체 설치본을 이 PC의 고유 임시 제품·경로에 설치하고 모든 명세 파일의 SHA-256을 확인했다. 재설치·설정 보존·설치된 Python·업적 스캐너 체크포인트·앱 자체 검사·제거를 통과했다. 실제 설치 등록과 계정은 사용하지 않았다.
- 실제 업데이트 도우미로 모의 버전 1.0.0 → 1.1.0 설치, 기존 프로세스 종료 대기, 설정 보존, 완료 후 홈 재시작, 제거를 통과했다.
- 최초 공식 원본 배경 교체 후 원본·PNG의 디코딩 픽셀 일치, 설치본 해시 일치, 이전 JPG 제외, 포장 목록의 실제 파일 복사, 설치본 출처 문서 링크를 확인했다. 설치된 GUI에서 배경과 채팅·하단 버튼 표시를 확인했고, 현재·전체 이력 개인정보 검사와 포장 스크립트 문법 검사를 다시 통과했다.

- 홍보 제목 제거 편집본의 PNG 형식·1672×941 크기·소스와 설치본의 해시 일치 및 설치본 문서 링크를 확인했다. 앱을 재시작해 제목이 사라진 배경과 기존 채팅·하단 버튼 배치를 확인했으며 현재·전체 이력 개인정보 검사를 통과했다. 이번 편집본으로 설치 파일을 다시 빌드한 것은 아니다.

## 반영한 정리

불완전한 desktop 소스 ZIP을 없애고 설치 파일과 SHA256SUMS를 같은 날짜별 폴더에 생성한다. 스캐너의 최초 사용 인식 목록 캐시는 빌드 입력으로 요구하지 않는다. 사용자 안내에 Windows 알림과 HDR·자동 HDR 프리셋 동작을 반영했다. Windows 자동 빌드·회귀 검사 구성을 추가했고, 게시 권한은 부여하지 않았다.

## 공개 전에 필요한 결정

2026-10-04 [zerossin/catheryne](https://github.com/zerossin/catheryne)를 공개 저장소로 생성하고 소스를 `main`에 게시했다. 첫 공개 커밋은 `9235dae`이며, 개발 커밋 `59c88d8`과 파일 트리가 일치하는 단일 커밋 스냅샷이다. 이전 그림이 포함된 개발 이력은 게시하지 않았다. 설치본 릴리스는 아직 게시하지 않았다.

아이콘과 환영 그림은 프로젝트 소유자가 직접 제작했다고 확인했다. 2026-10-04 사용자 선택에 따라 배경을 [원신 공식 「어느 겨울밤, 한 여행자」 콜롬비나 월페이퍼](https://www.hoyolab.com/article/43631587)로 교체했다. 처음에는 공식 1920×1080 JPEG를 픽셀 변경 없이 PNG로 변환했다. 이후 사용자 요청에 따라 ImageGen으로 오른쪽 위 홍보 제목을 제거한 1672×941 편집본을 소스와 설치본에 적용했다. 하단 저작권은 보존했으며 AI 편집으로 일부 세부도 달라졌다. 원본은 개인 백업에 보존하고 원본·편집본의 해시·출처·편집 기록은 branding/README.md에 기록했다. 코드 라이선스와 이미지 권리는 구분하며 별도의 재배포 허락이 확인된 것으로 기록하지 않는다.

기존 Reo 배경과 출처 미확인 JPEG는 현재 소스와 향후 설치본에서 제외하고 개인 백업에 보존했다. 이전 Git 이력에는 기존 그림이 남아 있으므로 전체 이력을 그대로 게시하지 않고 검토한 현재 파일의 공개 스냅샷을 사용한다. 앞선 20261004-162709 설치 검증본은 이전 배경이 포함된 과거 산출물이다.

별도 새 Windows PC, 실제 공개 GitHub 릴리스 설치본 조회·다운로드, 코드 서명은 아직 검증하지 않았다. GitHub의 개인정보·번역 검사는 통과했고 Windows CI의 앱·네이티브 DLL·스캐너·Python 런타임·AI 어댑터 검사는 통과했다. 한국어 앱 자체 검사에서 분리 화면 연결 COM 설정에 E_UNEXPECTED가 발생해 나머지 단계는 생략됐다. 사전 활성화를 요구하는 Windows 기능을 CI 테스트가 준비하지 않았음을 확인하고, 임시 GitHub-hosted runner에서 활성화 후 원래 상태로 복원하는 test-desktop-ci.ps1을 준비했다. 테스트를 생략하거나 실제 게임 입력을 보내지 않는다. 로컬 한국어·영어 자체 검사와 준비 단계의 상태 복원·실패 전파 검사는 통과했으며, 수정 후 GitHub 재실행은 아직 수행하지 않았다. Preview 릴리스는 앱의 자동 업데이트 대상이 아니다. 자동 업데이트는 정식 릴리스를 대상으로 하며 기본 꺼짐이다.

## 설치 페이지 준비

제로신 홈페이지 저장소의 `/catheryne/`에 영어 기본·한국어 전환 소개 페이지를 준비했다. 소개·그림·버튼 두 개·기능 카드 세 개로 구성하고 설치 절차는 별도 사용자 안내에 연결한다. 홈페이지 Tool 폴더와 앱 README에서 연결하며 Games 광고 배너는 향후 같은 주소를 사용할 수 있다. 설치본은 GitHub Releases의 실제 Windows 파일을 조회하고, 아직 없거나 조회가 실패하면 릴리스 목록으로 연결한다. 홈페이지 및 이 후속 소스 수정은 아직 원격 게시 전이다. 앱 실행 코드와 설치본은 이번 변경에서 수정하지 않았다.
