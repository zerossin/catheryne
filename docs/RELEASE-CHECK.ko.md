# 릴리스 검증

2026-10-07. `0.2.2 Preview`는 `0.2.1 Preview` 이후의 수정사항을 포함한다.

## 필수 점검

설치·업그레이드·재설치·제거, 설정 보존, 최초 실행, 설치 파일 무결성, 개인정보 제외를 확인한다. 선택 기능도 검사를 유지하며 실패를 통과로 기록하지 않는다.

## 이번 설치본의 변경

- 공식 CLI로 로그인한 Claude 계정으로 채팅하며 ChatGPT와 같은 앱 도구를 사용한다.
- 모델 선택 목록을 하나로 통합하고 채팅창 하단의 기존 배치를 유지한다.
- 게임 실행 환경(Windows 자식 세션)의 로그인 오류 상태가 이후 처리로 덮이지 않도록 수정한다.
- `.gitignore`를 보강하고 미사용 빌드 스크립트를 제거한다. README 버전 표시는 Preview를 포함한 최신 공개 릴리스를 자동으로 따른다.

한국어·영어 앱 검사, 공개 자료·Git 이력 검사와 설치 파일 무결성 검사를 통과했다. manifest의 4,515개 파일 해시와 개인정보 제외를 확인했다. SHA-256은 `SHA256SUMS.txt`에 기록했으며 공개·push·태그 생성과 실제 설치본 교체는 수행하지 않았다.

## 배포

[GitHub Releases](https://github.com/zerossin/catheryne/releases)에서 버전별 설치본을 제공한다. [설치 페이지](https://gitpage.zerossin.com/catheryne/)는 Preview를 포함한 최신 공개 설치본을 연결한다. 앱의 자동 업데이트는 정식 릴리스만 대상으로 하며 기본 꺼짐이다.

첫 `0.2.0 Preview`는 2026-10-04 공개했다. 이번에는 고유 시험 설치 ID·독립 경로에서 설치, `0.2.1 → 0.2.2` 경로 유지 업그레이드, 재설치, 설정 보존과 제거를 통과했다. 실제 AI 로그인·게임 조작, 비공개 게임 프레임 검사 10개, 별도 새 Windows PC 검증과 코드 서명은 미실행이다.

## 이미지

아이콘과 환영 그림은 프로젝트 소유자가 직접 제작했다. 배경은 [원신 공식 월페이퍼](https://www.hoyolab.com/article/43631587)의 편집본으로 하단 저작권을 보존했다. 출처·해시·편집 기록은 `branding/README.md`에 남겼다. 코드와 이미지 권리는 구분하며, 이전 외부 그림이 포함된 개발 이력과 개인정보는 공개하지 않는다.
