# v0.2.0 Preview 공개 점검

2026-10-04. 첫 Preview 설치본을 준비한 기록이다. 일반 설치·실행과 선택 기능인 별도 화면 AI 조작의 검증 상태를 구분한다.

## 공개 기준

- 설치·재설치·제거, 설정 보존, 최초 실행과 기본 기능, 설치 파일 무결성, 개인정보 제외는 필수다.
- 선택 기능의 검증 실패는 영향 범위와 알려진 문제를 공개한다. 선택 기능 하나의 CI 실패만으로 기본 앱의 Preview 설치본 전체를 보류하지 않는다.
- 실패한 검사를 생략하거나 통과했다고 기록하지 않는다. 별도 새 Windows PC에서의 검증과 코드 서명은 완료되지 않았다.

## 현재 설치본 검증

- 사용자와 AI의 기본 일반 실행을 회귀 검사했다. 별도 화면 실행을 접힌 고급 설정으로 옮기고, 일반 실행에서는 연결 버튼과 연결 상태 조회를 생략한다. 이미 선택한 분리 실행 설정은 보존한다. 앱 실행 화면 변경은 설치본에 포함한다. 별도 메모리 렌더링 검사에서 접힌 기본 상태·일반 실행 선택·분리 연결 버튼 숨김·기존 명시적 선택 보존·좁고 넓은 배치를 확인했다. 실제 사용자 창이나 마우스·키보드를 사용하지 않았다.
- 현재 소스의 WPF 앱·업데이트 도우미·캡처·이미지·Windows 알림 DLL을 다시 빌드했다. 한국어·영어 자체 검사가 모두 통과했으며, 이 PC에서는 별도 화면 연결 COM 설정 검사도 통과했다. 실제 게임 입력은 보내지 않았다.
- 현재·전체 개발 이력의 개인정보 검사와 번역 검사를 통과했다. 설치 payload 4,960개 파일에서 개인 설정·계정·캡처·기록을 제외했음을 확인했다. 외부 Python 라이브러리의 예제 경로·공식 빌드 경로·키 형식 구분 문자열은 실제 개인정보나 개인 키가 아님을 별도로 검토했다.
- 검증한 실행 파일, 공개 저장소 주소, 제목을 제거한 최신 배경을 포함한 `Catheryne-Setup-0.2.0.exe`를 생성했다. 파일 크기와 SHA-256은 같은 폴더의 검증 기록과 `SHA256SUMS.txt`에 기록한다.
- 같은 payload와 설치 스크립트를 사용하는 고유 임시 제품·경로에서 한국어 설치, 영어 재설치, 명세 4,959개 파일의 SHA-256, 번들 Python 실행, 설치된 앱 자체 검사, 제거를 확인했다. 설정과 사용자 생성 파일은 보존됐다. 실제 앱의 설치 등록·계정·실행 중인 GUI를 사용하지 않았다. 임시 제품은 실제 앱의 일일 알림 작업을 중지하지 않도록 분리했다.
- 이전 점검에서 두 스캐너·Python 런타임·AI 어댑터를 빌드하고 코어 Python 검사 159개 통과·10개 조건부 생략, Node 검사 6개 통과, 번들 AI 어댑터 검사 14개 및 MCP 초기화·21개 도구 계약을 확인했다. 실제 업데이트 도우미의 모의 버전 갱신·설정 보존·재시작·제거도 통과했다.

## 공개 저장소와 CI

[zerossin/catheryne](https://github.com/zerossin/catheryne)에 검토한 소스 스냅샷과 후속 수정 `763197f`를 게시했다. 이전 그림이 포함된 개발 이력은 공개하지 않았다. 설치본 릴리스는 아직 게시하지 않았다.

[개인정보·번역 CI](https://github.com/zerossin/catheryne/actions/runs/37191751930)는 통과했다. [Windows CI](https://github.com/zerossin/catheryne/actions/runs/37191751929)는 앱·네이티브 DLL·스캐너·Python·AI 어댑터 검사를 통과했으나, 한국어 자체 검사 중 별도 화면 연결 COM 설정에서 `E_UNEXPECTED`가 발생했다. 준비 단계에서 Windows 기능을 활성화해도 같은 실패가 남았다. 정확한 COM 속성과 원인은 아직 확정하지 않았으며 모든 사용자 PC에서 기능이 실패한다는 근거는 아니다. 일반 설치·실행은 이 연결을 요구하지 않는다.

첫 공개는 `v0.2.0-preview.1` 사전 릴리스로 준비한다. Preview는 앱의 자동 업데이트 대상이 아니다. 자동 업데이트는 정식 릴리스를 대상으로 하며 기본 꺼짐이다. 실제 공개 설치본 다운로드와 별도 새 Windows PC 설치는 아직 검증하지 않았다.

## 이미지와 설치 페이지

아이콘·환영 그림은 프로젝트 소유자가 직접 제작했다. 사용자 선택에 따라 배경은 [원신 공식 「어느 겨울밤, 한 여행자」 콜롬비나 월페이퍼](https://www.hoyolab.com/article/43631587)의 제목을 제거한 1672×941 편집본이다. 하단 저작권은 보존했으며 AI 편집으로 일부 세부도 달라졌다. 출처·해시·편집 기록은 `branding/README.md`에 남겼다. 코드 라이선스와 이미지 권리는 구분하며 별도 재배포 허락이 확인됐다고 기록하지 않는다. 기존 Reo 배경과 출처 미확인 그림은 공개 소스와 현재 설치본에서 제외했다. 이전 설치 산출물은 게시하지 않는다.

영어 기본·한국어 전환 설치 페이지를 홈페이지 저장소에 게시했고 [GitHub Pages 주소](https://gitpage.zerossin.com/catheryne/)에서 확인했다. 제로신 홈페이지 Tool 폴더와 README에서 연결한다. 실제 설치본이 공개되면 GitHub Releases에서 설치 파일을 찾아 다운로드 버튼에 연결한다. `zerossin.com/catheryne/`의 NAS 반영은 아직 확인되지 않았다.
