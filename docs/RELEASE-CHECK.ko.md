# 릴리스 검증

2026-10-06. `0.2.1 Preview`는 첫 공개 설치본 이후의 수정사항을 포함한다.

## 필수 점검

설치·업그레이드·재설치·제거, 설정 보존, 최초 실행, 설치 파일 무결성, 개인정보 제외를 확인한다. 선택 기능도 검사를 유지하며 실패를 통과로 기록하지 않는다.

## 이번 설치본의 변경

- 별도 화면 연결의 상대 마우스 설정은 이를 지원하는 RDP 클라이언트(Windows 11 24H2 이상)에만 적용한다. 필수 연결 설정은 실패 시 진행하지 않으며 오류에는 실패한 설정명을 표시한다.
- 편성 저장은 준비가 끝날 때까지 비활성화한다. 화면 배치와 문구는 유지한다.
- Windows CI는 번들 Python의 의존성을 사용하고, 비동기 패널 준비를 제한된 시간 동안 기다린다. 작은 화면의 검사 창도 지정한 폭을 사용한다.

수정 소스 `00ca669`의 [Windows 검사](https://github.com/zerossin/catheryne/actions/runs/37414480428)와 [공개 파일 검사](https://github.com/zerossin/catheryne/actions/runs/37414480435)는 모두 통과했다. 버전을 부여한 설치본은 별도로 다시 빌드·검증하고 공개한다. 설치 파일의 SHA-256은 릴리스에 함께 제공한다.

## 배포

[GitHub Releases](https://github.com/zerossin/catheryne/releases)에서 버전별 설치본을 제공한다. [설치 페이지](https://gitpage.zerossin.com/catheryne/)는 Preview를 포함한 최신 공개 설치본을 연결한다. 앱의 자동 업데이트는 정식 릴리스만 대상으로 하며 기본 꺼짐이다.

첫 `0.2.0 Preview`는 2026-10-04 공개했다. 당시의 선택 기능 COM 검사 실패는 위 후속 수정에서 해결했다. 개발 PC의 독립된 설치 경로에서 한국어·영어 설치, 재설치, 설치된 앱 자체 검사, 파일 해시, 제거를 확인했다. 별도 새 Windows PC 검증과 코드 서명은 아직 완료되지 않았다.

## 이미지

아이콘과 환영 그림은 프로젝트 소유자가 직접 제작했다. 배경은 [원신 공식 월페이퍼](https://www.hoyolab.com/article/43631587)의 편집본으로 하단 저작권을 보존했다. 출처·해시·편집 기록은 `branding/README.md`에 남겼다. 코드와 이미지 권리는 구분하며, 이전 외부 그림이 포함된 개발 이력과 개인정보는 공개하지 않는다.
